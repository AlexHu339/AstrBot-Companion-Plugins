# LivingMemory 小鱼陪伴版

基于 LivingMemory 2.8.2，保留 lxfight 的署名和 AGPL-3.0 许可证。本快照包含 companion.14 的记忆管理、预算隔离、八种情绪、费用/资源看板、旧记忆安全整理与新消息优先转接。

- `companion` 视图：费用、空间占用、情绪、聊天节奏与检查记录。
- `dashboard` 视图：记忆查看、更正、置顶、删除、搜索、导出与管理；索引重建沿用管理员命令 `/lmem rebuild-index`。
- 模型 Provider ID、主人身份与数据目录使用你自己的配置；默认数据目录留空，由 AstrBot 插件数据目录处理。
- 原文、关键事实、连续状态、目的和外部见闻分开。置顶和重要记忆受保护；旧记录优先归档，整理保留来源。
- 新消息到来时，旧轮未发送的碎句可停止，新回答就绪后接话；不会把未发草稿当成已经说过的事实。不更改你已有的人格、主动提示词和分段间隔。
- 费用观察包括已适配的聊天模型、语音和唱歌；仅按本机观察到的请求与配置价格核算，缺少用量或价格会提示待核对，不能代替平台账单。

本仓库不包含维护者的聊天、记忆、人格、API Key 或真实账号设置。详见 [安装说明](../../docs/INSTALL.md) 和 [本地定制说明](../../docs/LOCAL_CHANGES.md)。
