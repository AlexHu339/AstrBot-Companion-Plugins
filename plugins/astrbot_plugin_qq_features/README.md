# qq功能拓展 2.2

一个AstrBot插件，按“聊天互动、QQ资料、空间与见闻、记录与用量”组织。每个功能的权限与参数放在同一处；同一种资料的被动与主动权限并列。顶部或底部一次保存全部设置，未保存输入不会被刷新抹掉。共用的滚动周期与延迟时间在两处同步显示。

## 聊天互动

戳后说话、回戳、聊天中主动戳分别开关。引用历史时长与撤回有效时限、自动撤回等待独立。只接受当前主人私聊中的真实消息与回执，不猜消息编号。沿用AstrBot原生分段和延迟。

自然接话复用当轮聊天模型，按概率与轮次间隔提供轻松的接续机会：夸张、改口、分享具体感受或留下一个可回应的小主张，不复读固定示例、不每轮反问、不强行拖住对方。认真、难过、忙碌和收尾时避开调皮接话。当前本机分段正则的分隔字符不包括ASCII句点，因此“最最最...可爱”和中文省略号不会从中间按句点切开；不改动宿主正则。

## 成功收藏表情后的互动

“聊天互动”页有独立开关，默认45%机会、10分钟冷却、每天最多5次。现有表情包管理器仍是唯一的筛选、分类和存储入口。本功能通过可卸载的运行时适配确认正式图片和语义描述已提交后才回应；不修改原插件文件，不把待审核、重复、失败或回滚视为成功。主人来源、实际图片摘要及同一消息均去重。

复用收图时已有的描述与当前人格、记忆、目的、上下文和情绪，不再识图。能赶上本轮请求则在同轮自然接一句；识别较慢时，等待原回复完成后才考虑补一条短句，费用单列“表情收藏互动”。新用户消息、超过三分钟或免打扰会取消旧补发；不会建立新的定时主动聊天器。正常聊天不因为启用本开关持续增加提示词。真正发送的补充才写入助手历史，不虚构用户发言，不强行写成用户偏好或承诺。

概率与冷却限制的是互动，不改变自动收集参数。界面提供适配连接状态。插件重载/卸载恢复自己持有的原方法，表情包管理器重载后会重新连接。

## QQ资料

昵称、头像、个性签名和在线状态分别有“听你要求”与“允许小鱼主动”两种权限。自动变化以当前保存的人格为主，结合记忆、目的、近期上下文和情绪；不是固定昵称或签名模板。

主动资料默认有35%的可用机会供模型考虑；每天最多修改2个项目。一次机会的并发上限可设1至4项，默认2；随机数量默认开启，在0至可用上限之间取数，再由当前人格、情绪、目的和语境选择具体项目，允许少改或不改。实际数量受当天剩余项目额度约束，一次改2项使用2个额度。四项分别计算冷却，默认同一项6小时，允许设为0；换昵称不会锁住头像、签名或状态。手动修改只让对应项目进入冷却。昵称、签名与头像近期去重；状态避免连续改成同一个，并允许以后自然回到常态。新回复、人格切换、关闭权限、免打扰或额度变化会使旧想法失效。网络写入结果不明确时保留待核对，不自动重复。多项QQ操作依次提交，按字段记录真实结果，不虚报整组成功；并行工具请求也不能突破本轮、同项去重或每日总额度。

自动头像只从当前会话启用的表情包分类选取，沿用meme_manager的表情包选择规则，不另建表情收集器、不接受模型指定电脑路径。GIF和动态WebP只在内存抽取静态帧，再转为静态头像，不改动原文件。支持已核对的真实QQ状态，包括“爱你”“摸鱼中”“元气满满”“想静静”等；最终成功与否以NapCat实际回执为准。

## 空间与见闻

主人在私聊发来的QQ空间动态链接或分享卡片默认可读取并触发一次正常回复，不依赖主动浏览开关；公开评论有独立子权限，关闭只在QQ中回复。标准说说链接读取详情；接口无法核实全文或分享卡片不带可解析身份时，只根据分享预览回应，不声称看过全文，也不编造评论目标。你问“今天有什么见闻”时读当天真实记录，不虚构今天看过的内容。

主动浏览有一个总开关，下面选择主人、好友可见历史、空友爱看，以及是否允许评论。每日次数设0也会停止主动浏览，没有第二个“每天随机逛空间”开关。每趟少量读取，好友历史保存翻页位置并轮换好友；只能访问当前QQ账号实际可见内容，图文与视频封面都有来源。推荐流保留自身原始身份和评论路由，不拿普通tid伪造公共动态。

发说说只有一个自主发表权限，结合真实聊天、爸爸的状态、见闻或关联感受，受滚动额度、概率和去重约束，发布前不逐条请示。聊天结束或主动消息未获回复后的资料／说说候选共用随机等待；每次最多选择一个公开行动。私聊的发送时机、免打扰和未回复上限仍由既有Proactive Chat决定，候选话题不会新增、提前或重排私聊任务。

见闻随流程自动维护，不再暴露“保存见闻”开关。近期原文与长期观察分开，少量有价值内容进入LivingMemory并标记为外部来源，别人的经历不会进入主人的固定事实。分享感受走已有聊天、记忆、情绪、TTS与表情包管线；真实链接缺失时转述，不编造转发卡片。旧草稿审核不再进入日常界面；内部提交状态与幂等记录保留以防不确定写入后重发。

## 默认费用与节奏

- 自动浏览每天最多2次，一趟最多3条；识图一趟默认1张，可设0～20，多张图按来源分别对应。
- 自主说说与评论分别每滚动5天最多2次；资料变化另外计数。已有用户设置在升级时保留。
- 后台空间／资料自主决策共用每日额外决策上限，默认6次；识图单独统计。时钟检查和QQ接口、静态帧处理本身不消耗聊天token。
- 聊天接话和当前聊天的资料动作复用当轮模型。后台“空间自主决策”“资料自主决策”“空间看图”使用既有LivingMemory费用账本；缺用量或缺价格会标待核对，不当成免费。

本机数据仍在D:/AstrbotData/qq_features/qq_features.db，长期记忆仍在原LivingMemory目录。Cookie、完整推荐互动上下文与分页游标仅在内存使用，不写配置、日志或导出。修改与接口来源见THIRD_PARTY.md。组合插件AGPL-3.0，既有空间传输组件GPL-3.0，完整对应源代码与授权随安装包提供。
