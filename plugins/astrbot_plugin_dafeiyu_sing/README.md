# 小鱼唱歌 · 本地定制快照

上游：zexuanw958-svg/dafeiyu-config-pack，作者 zexuan604 / zexuanw958-svg，原始 MIT 许可保留在 LICENSE。早期说明见 README_UPSTREAM.md。

默认使用豆包 Seed Audio 云端后端，可按现有人格、话题和记忆写短歌，支持更多歌名、主题、原创歌词和哼唱。需要在自己的火山项目另行开通音频生成服务；可选择复用 CloneTTS 的 API Key 与已有音色。声音复刻字符额度不能替代音频生成额度，克隆音色跨服务可用性以实际返回为准。

不保证任意原曲旋律或声线完全一致。实际生成结果和时长通过已有用量衔接写入 LivingMemory；没有 LivingMemory 时本插件仍保留自身用量记录，具体以代码与平台账单为准。

分享包不带凭据、音色授权、参考录音、生成音频或试用额度。本地 SoulX 后端为可选项，使用时自行准备有使用权的参考录音和对应标注。

安装与 Provider 配置见 [合集安装说明](../../docs/INSTALL.md)。
