# 本地定制和公开副本改动

本仓库直接取自已安装插件的源码快照，不包含安装目录中的实际账号配置与运行数据。

- LivingMemory：长期记忆预算与身份隔离、事实/连续状态/目的组织、八种情绪（含委屈）、重要记忆保护及安全整理、记忆管理、费用/资源看板、逐条交付和新消息优先转接。打断后仅用实际送达的文字更新记忆与情绪，未完整发送的草稿留检查记录。
- QQ 拓展：统一的聊天、资料、空间和见闻功能；开关与参数按功能组织；手动/自主权限、去重、频率和真实回执；与记忆、情绪、主动聊天及表情收集配合。保留第三方 Qzone 源码和许可证。
- Proactive Chat：适配已有记忆请求/回应管线与语音、费用观察，继续复用其调度、上下文和免打扰。
- 表情包管理器：区分“语义可用”和“分类可信”；清楚的表情描述可自动入索引；辅助模型后台选图，文字先发送；过期轮次/人格切换不补发迟到图片。
- CloneTTS：声音复刻请求与音频处理适配，PCM 可使用标准库封装 WAV；与已有语气和用量记录衔接。
- 唱歌：云端 API/凭据复用、可选已有克隆音色、更多歌名/主题/原创歌词、生成结果反馈和用量记录；保留本地 SoulX 可选接口。

公开副本仅调整打包内容与说明：排除运行数据、缓存、参考录音和标注；QQ 拓展的数据目录默认值改为空以使用插件数据目录；为唱歌插件补入原配置包根目录的 MIT 许可证；补充公开安装说明。没有改动维护者正在运行的插件或配置。

原项目 README/描述可能记录上游原版或早期功能；当前适配以源码、元数据和本仓库安装说明为准。每个插件仍保留原作者与授权，不将原项目全部宣称为本地原创。
